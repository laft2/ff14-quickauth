# FF14 QuickAuth ⚔️

FINAL FANTASY XIV 公式ランチャー専用の軽量・高機能な認証補完マネージャー（Windowsデスクトップアプリ）です。  
ランチャー起動時にフローティングオーバーレイが表示され、**ワンクリックでパスワードおよびワンタイムパスワード（TOTP）を安全に自動入力**します。

---

## 📥 ダウンロード & インストール

最新バージョンは **[GitHub Releases ページ](../../releases/latest)** から直接ダウンロードいただけます。

ご利用方法に合わせて、以下の2種類のパッケージからお選びいただけます：

| パッケージ形式 | ファイル名 | おすすめの用途 |
|---|---|---|
| **💾 インストーラー版** *(推奨)* | `ff14-quickauth_..._x64-setup.exe` | ダブルクリックで簡単インストール。スタートメニューや自動起動に登録して使いたい方向け。 |
| **📦 ポータブル版** | `ff14-quickauth-v...-portable.zip` | インストール不要。Zipを解凍するだけでそのまま使えるポータブル派向け。 |

## ✨ 主な機能

* **🚀 ワンタッチ自動入力**
  * FF14ランチャーの起動をバックグラウンドで自動検知し、画面上にフローティングボタンを表示。
  * 既存文字列の全選択消去（`Ctrl+A` -> `Backspace`）後に、パスワードおよびTOTPを自動入力。
* **🔐 セキュアな認証情報管理**
  * 入力したパスワードおよびTOTPシードは、Windows標準の暗号化基盤である **Windows 資格情報マネージャー (DPAPI)** を使用してローカルに安全に保存されます。
  * メモリ上の資格情報は使用後に即時ゼロ埋め消去（Zeroize）されます。
* **📱 Google Authenticator / QRコード解析**
  * Google Authenticator等のエクスポートQRコード画像（`otpauth-migration://`）の読み込み、ドラッグ＆ドロップ、クリップボード画像貼り付け解析に対応。
* **⚙️ Enter 自動ログイン & 自動起動**
  * 入力完了後の Enter 自動送信トグル機能（ON/OFF設定は自動保存されます）。
  * Windowsログイン時の自動起動連携対応。

## 🗑️ アンインストール方法

* **インストーラー版**: Windowsの **「設定」➜「アプリ」➜「インストールされているアプリ」** から「FF14 QuickAuth」を選択して「アンインストール」をクリックするだけで綺麗に削除されます。
* **ポータブル版**: 解凍したフォルダを削除するだけで完了します。
